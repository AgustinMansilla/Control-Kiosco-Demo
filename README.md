# 🕒 Control Kiosco — Gestión de personal y turnos

Sistema web para registrar la actividad del personal, administrar jornadas de trabajo y consultar cobros e historial desde computadoras y celulares.

**Desarrollo:** Agustín Mansilla Emanuel

---

## Funcionalidades

- Registro de entradas, salidas y asistencia por turno.
- Organización de horarios y jornadas.
- Consulta y administración de empleados.
- Seguimiento de horas trabajadas, movimientos y pagos.
- Panel administrativo para supervisión y reportes.
- Interfaz adaptable a dispositivos móviles.
- Soporte para uso como aplicación web progresiva (PWA).

## Tecnologías

| Componente | Tecnologías |
| :--- | :--- |
| Backend | Python, Django |
| Interfaz | HTML, CSS, JavaScript |
| Base de datos | PostgreSQL |
| Plataforma | Web y PWA |

## Interfaz del sistema

- [**Pantalla de personal**](presentacion/index.html): consulta de turnos y registro de asistencia.
- [**Panel de administración**](presentacion/administrador.html): gestión de jornadas, personal y cobros.

Las páginas incluyen estilos y estructura provenientes de las plantillas del sistema, con registros de ejemplo.
